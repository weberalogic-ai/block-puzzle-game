# Weberalogic Block Puzzle Game

A modern, mobile-first Block Puzzle Game built with plain HTML, CSS and JavaScript.

## Features
- Responsive 10×10 puzzle board
- Touch/pointer-friendly controls
- Multiple block shapes
- Row and column clearing
- Score and persistent best score using localStorage
- New Game and Play Again controls
- No backend or external dependencies
- GitHub Pages compatible

## Run
Open `index.html` in a browser, or enable GitHub Pages for the repository.

Repository: https://github.com/weberalogic-ai/block-puzzle-game
